Privacy Policy

Last Updated: October 2, 2026

Personal Use Notice: This application is locally hosted, privately operated, and solely used by the developer. It is not intended for commercial distribution or multi-user access.

1. Overview

This Privacy Policy outlines how user data is handled by this private, local application. Because this application is restricted to a single-user local environment, no data is collected, stored, or processed by any third-party external server apart from the official WHOOP API ecosystem.

2. Data Collection via WHOOP API

This application connects to the WHOOP API to access your personal physiological and performance metrics. Depending on the explicit scopes granted during authentication, the data processed locally may include:

  • User Profile information
  • Cycle, Sleep, Recovery, and Workout metrics
  • Heart rate telemetry and physiological measurements

3. How Data is Used and Stored

Any data retrieved from the WHOOP API is handled with strict local boundaries:

  • Local Execution: Data is requested directly from your local machine and remains within your local environment.
  • No External Transmission: Your data is never sold, shared, rented, or transmitted to external databases, analytics trackers, or third-party developers.
  • Token Security: Authentication credentials and access tokens are saved locally in your environment variables or local database configuration files.

4. Data Deletion and Revocation

You retain full control over your data connectivity at all times:

  • To erase locally cached data, simply delete the local database or storage configuration files on your machine.
  • To completely sever the application's access to your data, log into your official WHOOP account dashboard and revoke access permissions for this application under your Integration settings.

5. Contact Information

As this is a private development application for personal use, support and inquiries are managed directly by the developer within the local development environment.
